# IO HELPER

Chrome-расширение (Manifest V3) для модераторов проекта [CYBERSHOKE](https://cybershoke.net). Модераторские функции работают в админке `https://io.cybershoke.net` и `https://io.cybershoke.ru`. На обычных `cybershoke.net` / `cybershoke.ru` (включая `www`) работает только учёт ручных подключений к серверам.

Расширение не заменяет штатный интерфейс сайта: оно дополняет очередь жалоб и открытый тикет подсказками, подсветкой и автоматизацией рутинных действий. Обработка идёт в браузере; удалённо запрашиваются только конфигурация, данные игрока и перевод — см. [Privacy Policy](privacy-policy).

Текущая версия: **2.14.3** (поле `version` в `manifest.json`).

## Возможности

Параметры доступных функций — в popup расширения.

**Трекер**
- текущий сервер нарушителя в таблице жалоб (онлайн / оффлайн / сменил сервер);
- VIP-бейдж (цвета PREMIUM / LITE по брендбуку) и связанные статусы;
- подсветка активного мута, бана, модератора и верифицированного профиля.

Трекер циклически проверяет игроков из всей очереди через API CYBERSHOKE и использует уже полученные штатные ответы. Интервал в popup — пауза после полного прохода; при открытом тикете действует отдельная замедленная пауза. Открытый игрок проверяется первым. Один ответ сразу обновляет текущий сервер, часы и Faceit в общем хранилище. FastMM для Faceit не используется.

Новые жалобы проверяются сразу отдельным проходом по новым строкам, сохраняя срок следующего полного обхода. В текущем проходе новые жалобы получают приоритет после уже отправленного запроса. Перерисовка известных строк не запускает их досрочную повторную проверку.

**Подсветка**
- триггеры в тексте жалобы;
- новые аккаунты по часам CYBERSHOKE;
- дубликаты серверов в очереди.

**Открытый тикет**
- автовыбор причины закрытия жалобы по категории, таймеру, нажатию подтверждения бана/мута и состоянию нарушителя по трекеру (по умолчанию выключен). Ручной выбор сохраняется, тикет расширение не закрывает;
- анализ чата и истории наказаний с подсказкой срока и причины;
- сразу после подтверждения бана/мута бейдж анализа меняется на «ЗАБАНЕН» / «АКТИВНЫЙ МУТ». До появления записи в истории ховер отсутствует; затем показывает реальную запись. Дополнительных запросов API нет, автовыбор причины закрытия для этого не требуется;
- детект consecutive spam и ограничение числа триггеров в бейдже анализа;
- дата создания Steam-аккаунта, часы CYBERSHOKE и флаг страны;
- Faceit ELO и готовый уровень из штатного профиля игрока; FastMM используется только для даты создания Steam;
- подсветка жалобы и значки возле каждого участника, если отправитель или нарушитель — модератор/администратор;
- компактное число заблокированных аккаунтов без скобок рядом со штатным статусом обхода;
- перевод нерусских сообщений при наведении;
- автоподключение к серверу (`steam://connect/…`) по категории жалобы и триггерам.

### Автовыбор причины закрытия жалобы

Включается в popup → «Открытый тикет» → «Автовыбор причины закрытия жалобы». Порог времени для читерства по умолчанию равен 3 минутам; его можно изменить в том же разделе. Используется таймер рассмотрения в самой жалобе.

| Причина жалобы | Без подходящего наказания | После кнопки подтверждения наказания |
|---|---|---|
| Читерство | «Читов не найдено»; при таймере ≥ порога — «Недостаточно доказательств» | Бан → «Нарушитель был наказан» |
| Багоюз | «Нет нарушений», без зависимости от таймера | Бан → «Нарушитель был наказан» |
| Мониторинг, Спам, Попрошайничество | «Нет нарушений», без зависимости от таймера | Мут → «Нарушитель был наказан» |

При нажатии «Выдать ограничение» или «Заблокировать» соответствующая причина выбирается сразу. Автовыбор не запускает дополнительные запросы API ни при отправке, ни после закрытия формы. Открытие формы ничего не меняет. Явная ошибка формы или отмена снимает предварительный выбор. Подходящий активный бан/мут, ранее обнаруженный существующим трекером до принятия тикета, также выбирает «Нарушитель был наказан».

Если трекер обнаружил выход игрока, выбирается «Игрок вышел с сервера». Возвращение на прежний или другой сервер снимает эту причину и возвращает управление категории, таймеру и наказаниям. Подходящее наказание имеет приоритет над выходом, поскольку бан сам может отключить игрока от сервера.

Любой ручной выбор причины сохраняется до конца этой жалобы. Функция не изменяет чужие и закрытые жалобы и не нажимает «Закрыть тикет». Прочие категории, включая «Нарушение правил», автоматически не обрабатываются.

При включённых трекере и автоподключении вышедший нарушитель проверяется отдельно примерно каждые пять секунд, пока его жалоба открыта. Компактная плашка внизу остаётся на время ожидания; после обнаружения кратко показывает результат и отправку команды подключения. Она не подтверждает реальный вход в игру. Скрытые SPA-сессии сохраняются, проверки исходной жалобы/анализа/последнего endpoint остаются. Неизменный статус не отменяет последующий ручной выбор сервера.

Наведение на бан, мут или предупреждение показывает HTML соответствующей записи сайта. До её появления расширение не создаёт сокращённую карточку из JSON. Иконки Faceit 1–10 используют актуальные векторные формы; при существующем аккаунте без актуального уровня показывается «?», без аккаунта строка скрыта.

**Другое**
- подстановка причины мута из анализа чата; срок, включая X2, выбирает сайт;
- кнопки «Выдать мут» / «Выдать бан» в тикете (через launcher папки management);
- квадратные карточки тикетов;
- сканирование расписания модераторов;
- шаблоны комментариев в уведомлениях и тикетах.

В форме мута расширение выбирает причину из анализа чата, а при отсутствии подходящей подсказки — «Токсичность». Это поведение работает всегда при включённом расширении и не имеет отдельного переключателя. Ручной выбор причины, включая кнопку «Выбрать» в блоке «Рецидив по другой причине», передаёт дальнейшее управление формой сайту до смены Steam ID или открытия новой формы. Сроки мута и бана, включая X2, рассчитывает сайт по выбранной причине; расширение их не меняет.

Расширение запоминает последний ручной или автоматический connect на админке и ручное подключение на обычном сайте CYBERSHOKE, включая ссылки `steam://rungameid/730//+connect IP:порт`. Адрес общий для вкладок сайта и админки: после ручного подключения на сайте повторное автоподключение к тому же серверу в тикете пропускается, в том числе после перезапуска браузера. Следующий connect заменяет адрес. Сохраняется только последнее намерение подключения (адрес, время, источник), без истории, паролей и параметров Steam-ссылки; фактический вход в игру расширение не проверяет. Ручной повторный connect остаётся доступен.

Триггер в тексте жалобы (например, «препятствует» или «ахк») разрешает автоподключение сразу, без ожидания анализа чата и независимо от его вердикта. Без триггера для «Нарушения правил», «Спама» и «Попрошайничества» расширение ждёт завершения анализа через await: разрешены результаты «нет нарушений» или «предупреждение», фиксированной паузы нет. Уже действующее наказание блокирует этот путь; таймаут, ошибка и незавершённый анализ без триггера подключения не разрешают.

## Установка (unpacked)

1. Клонировать репозиторий и установить зависимости:

```bash
git clone https://github.com/K4NT1K/IoHelper.git
cd IoHelper
npm install
npm run build
```

2. В Chrome открыть `chrome://extensions`, включить **Режим разработчика**.
3. **Загрузить распакованное расширение** и указать **корень этого репозитория** (каталог с `manifest.json`).

После изменений в JS снова выполнить `npm run build` (или держать `npm run watch`).

## Сборка

| Команда | Назначение |
|---------|------------|
| `npm install` | зависимости для сборки и линта |
| `npm run build` | `dist/content.js` и `dist/chunks/moderator.js` |
| `npm run watch` | пересборка при изменении исходников |
| `npm run lint` | ESLint |

Content script в манифесте — `dist/content.js`. Исходники: `content.js` и `modules/`.

## Конфигурация

Порядок загрузки (см. `modules/ConfigService.js`):

1. свежий кэш в `chrome.storage.local`;
2. `config.json` из этого репозитория (`raw.githubusercontent.com`);
3. встроенный `config.json`.

Конфиг проверяется фоновым service worker раз в час через Chrome Alarms, с timeout 8 секунд и проверкой структуры. Ошибка сохраняет последнюю рабочую копию. Новая ревизия применяется открытыми страницами; при открытой форме наказания — после её закрытия. Личные настройки сохраняются поверх defaults. Сон/выключенный Chrome и offline могут задержать обновление; код расширения через config.json не обновляется.

Пользовательские переключатели пишутся в `chrome.storage.local.helperSettings` из popup. «Обновлять состав ежедневно» получает семь дней через GET `/api/moderation/worktime/0…6` (0 — воскресенье, 6 — суббота) в существующей авторизованной вкладке. Alarm — 1440 минут, общий guard — 24 часа, без открытия вкладок и переключения дней. Только полная успешная неделя заменяет список. При закрытом Chrome, отсутствии входа или ошибке остаётся последний рабочий состав; обновление возобновляется, когда админка доступна.

В popup доступна **Статистика модераторов**: один профиль либо сравнение двух SteamID64 за 7/30/90 дней, свой период или всё доступное время с 01.01.2019. Сборщик использует штатный HTTP-клиент в уже открытой авторизованной админке: без открытия профилей и переключения вкладок. Баны и муты запрашиваются одним полным диапазоном; выбранный период применяется локально. Недоступные метрики и границы истории показаны отдельно. API рабочего времени может возвращать ограниченную историю — такие данные отмечаются как частичные. Кэш агрегатов хранится локально, очистка — на странице статистики.

**Liquid Glass** включается в popup либо через aside → профиль → Кастомизация. Есть три уровня прозрачности; настройка независима от палитры сайта. Оформление распространяется на навигацию, карточки, таблицы, формы и меню, с плавными переходами и поддержкой уменьшения движения.

Шаблоны комментария к тикету начинаются кнопкой **Токсичность**: один клик добавляет «Мут Токсичность». Тройной клик по «Оск» больше не выбирает токсичность. Шаблон только заполняет поле, не отправляет тикет и не выдаёт наказание.

В аналитике используются аватары из ответа профиля. Соотношения компактно показывают все наказания на 100 закрытых тикетов/жалоб; разбивка на баны/муты и их доли открывается наведением, фокусом или нажатием на подсказку. Это отношение объёмов, не процент тикетов, приведших к наказанию; при неполных данных или нулевой базе показан прочерк.

Оба поля поддерживают поиск по нику и SteamID среди модераторов из конфига и последнего состава API. По умолчанию «Сравнить всех модераторов» использует API расписания, проверяя его перед сбором. Можно явно выбрать конфиг или объединение без дублей. Jail/HNS/Movement исключены из командного рейтинга. Должность берётся из `class_name` профиля; в конфиге `moderators.Tier` содержит подразделы Senior Moderator, Advanced, Tier 1–5 и New moderator. Другие группы остаются для подсветки на сайте.

Основной показатель **«Импакт»**: `(баны + муты) / (закрытые тикеты + репорты) × 100`. Рядом показана база жалоб; число может превышать 100. Это отношение объёмов, а не доля жалоб с доказанным наказанием и не оценка качества решений. Доступны плавные сравнительные полосы, анимированный подиум и раскрываемые карточки фактов. Лёгкая глубина реагирует на курсор; reduced-motion отключает движение.

«Первое наказание» — минимум всех доступных банов и мутов с 01.01.2019, включая снятые, независимо от периода и фильтра отображения. Это ориентир начала деятельности по доступной истории, а не подтверждённая дата назначения. При неполном ответе дата отмечается соответствующим образом.

В консоли админки `await ioHelperModerators()` возвращает сохранённые разделы модераторов и метаданные состава без нового скана. Для копирования: `copy(JSON.stringify((await ioHelperModerators()).moderators, null, 2))`. Автообновление хранит список в Chrome, а файл `config.json` в GitHub автоматически не меняет. Новый вложенный конфиг требует IoHelper 2.12.0: сначала обновите расширения, затем публикуйте новый конфиг.

Сбор команды можно остановить и продолжить, в том числе после закрытия вкладки. Последний состав, период и полученные агрегаты сохраняются локально отдельно от 30 последних индивидуальных выборок. После трёх ошибок подряд сбор приостанавливается; неудачные запросы можно повторить. Даты получения и предварительный характер незавершённого рейтинга указаны на странице. Очищение кэша удаляет и общий рейтинг. Скан расписания при сравнении не запускается.

После переноса на другой ПК замените файлы корня расширения целиком, включая `dist` и новые модули. В `chrome://extensions` нажмите ↻, затем обновите все страницы админки. Версия в popup должна совпасть с manifest.json; технический отпечаток сборки хранится только в build-info.json. Отсутствие `isHeadshotsOnly` в `dist/content.js` означает старую сборку.

## Структура

```
content.js                 точка входа content script
background.js              service worker (FastMM только для даты Steam)
popup.html / popup.js      настройки
manifest.json
config.json                правила мута, шаблоны, дефолты
modules/App.js             координация наблюдателей и сервисов
modules/DOMCoordinator.js  события DOM
modules/TicketService.js   фасад тикета
modules/ticket/            анализ чата, трекер, автоконнект, наказания
modules/native/            наблюдение ответов сайта, нормализация и память страницы
modules/shared/            RuleMatcher, DOM-хелперы
css/                       стили, которые инжектятся на сайт
dist/                      собранные бандлы
```

## Приватность

Расширение не отправляет телеметрию. Статистика модераторов обрабатывается локально. Внешние запросы нужны для функций (сайт CYBERSHOKE, GitHub `config.json`, FastMM, сервисы перевода). Полный текст: [privacy-policy](privacy-policy).
